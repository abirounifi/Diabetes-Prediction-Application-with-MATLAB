# Diabetes Prediction Application

**Team Project | Biomedical Engineering | INTeK | 2024–2025**

## Overview

This project focuses on developing an interactive application for diabetes prediction using MATLAB and MATLAB App Designer. A Support Vector Machine (SVM) model is used to classify individuals as diabetic or non-diabetic based on selected medical and demographic parameters.

The project combines medical data analysis, machine learning, and graphical user interface development to explore the use of predictive models in healthcare.

## Objectives

- Explore diabetes, its risk factors, diagnosis, and complications.
- Analyze and visualize medical data.
- Develop a machine learning model for diabetes classification.
- Design an interactive graphical user interface for predictions.
- Explore the potential of machine learning in healthcare applications.

## Technologies Used

- **MATLAB** — Data processing and model development.
- **MATLAB App Designer** — Interactive graphical user interface.
- **Support Vector Machine (SVM)** — Supervised learning and binary classification.
- **Pima Indians Diabetes Dataset** — Dataset used for model development.

## Dataset

The project uses the Pima Indians Diabetes dataset, which includes the following input features:

- Number of pregnancies
- Glucose level
- Blood pressure
- Skin thickness
- Insulin level
- Body Mass Index (BMI)
- Diabetes Pedigree Function
- Age

The target variable represents the diabetes outcome.

## Application Features

- Enter patient-related parameters through a graphical interface.
- Process the input features using a trained SVM model.
- Display the predicted classification: diabetic or non-diabetic.
- Present the result through an interactive interface.

## Methodology

1. Import the dataset into MATLAB.
2. Explore and visualize the data.
3. Prepare the input features and target variable.
4. Train an SVM classification model.
5. Integrate the trained model into the MATLAB application.
6. Test the application using input examples.


## Disclaimer

This project is developed for educational and research purposes only. Its predictions are not a medical diagnosis and should not replace professional medical evaluation.

## Future Improvements

- Evaluate model performance using additional classification metrics.
- Explore alternative machine learning algorithms.
- Expand the dataset to improve the representation of different populations.
- Enhance the user interface and application functionality.
